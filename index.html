📋 신청 안내

  • 도메인은 검토 후 24시간 이내에 발급됩니다
  • 사용 기간은 무제한이며 추가 비용이 없습니다
  • 네임서버는 신청 후에도 변경 가능합니다
  • 부적절한 용도로 사용 시 도메인이 회수될 수 있습니다

🔧 네임서버란?

네임서버는 도메인을 실제 서버로 연결해주는 시스템입니다. 호스팅 업체에서 제공하는 네임서버 주소를 입력하시면 됩니다.

문의사항은 GitHub Issues로 남겨주세요
